Mail relay — 2 minute setup

A web page cannot send email by itself. Deploy this free relay once and every coach request leaves the kiosk silently, in the background. It needs no server and no cost.

  1. Open script.google.com and start a new project.
  2. Delete the sample code and paste the script below.
  3. Deploy → New deployment → type Web app → Execute as me → Who has access Anyone.
  4. Copy the /exec URL, paste it into Relay URL above, then Save delivery.
  5. Press Send test alert — every coach on alert should receive it.
// Coach-request mail relay for the group sign-in kiosk.
// Paste into script.google.com, deploy as a Web app (access: Anyone),
// then put the /exec URL into Coach alerts > Email delivery.
function doPost(e) {
  var d = JSON.parse(e.postData.contents);
  var to = (d.to || []).join(',');
  if (!to) { return ContentService.createTextOutput('no recipients'); }
  MailApp.sendEmail({
    to: to,
    cc: d.cc || '',
    subject: d.subject || 'Coach request',
    body: d.body || ''
  });
  return ContentService.createTextOutput('sent to ' + to);
}

Treat that URL like a password: anyone holding it could send mail through your relay. If it leaks, delete the deployment and make a new one.
